## Screen Capture Overview

ShareX defines workflows as tasks: capture region, apply an effect, run an annotation, then upload or save. Hotkeys trigger each workflow directly. The built-in editor handles arrows, text, and cropping.

Users capture a UI bug with an arrow pointing at the problem, record a short repro clip, and upload to a shared host. ShareX features that come up include region capture, scrolling capture, and the destination configuration. A ShareX download is often paired with an internal image host.

Buyers compare ShareX, which is free and open source, with Snagit and read ShareX reviews about configuration complexity. Alternatives include Greenshot and built-in snipping tools. It replaces a screenshot tool plus a separate uploader for technical work.

## Getting Started Playbook

Install the application and choose a save folder that is not synced to a service you do not control. Configure one upload destination before creating workflows. Test a simple region capture with a hotkey.

Build a workflow that captures, opens the editor, and uploads on confirm. Read ShareX reviews about hotkey conflicts and adjust combinations. Keep the destination list short, since each entry is a place data can leak to.

License/activation? Re-enter upload credentials when transfers fail silently.  
Compatibility? Update when a Windows graphics change breaks region selection.
